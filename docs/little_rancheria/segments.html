herd <- "little_rancheria"

Read caribou movement (gps) data

Code 
y <- st_read(paste0("../../data/",herd,"/caribou.gpkg"), "gps", quiet=TRUE)
spring <- y |> filter(migration=="Spring migration")
fall <- y |> filter(migration=="Fall migration")

Spring migration pathways

Each panel shows one individual’s spring migration tracks, with years distinguished by color. A couple things worth noting:

  • Most individuals show a fairly consistent southwest-to-northeast trajectory across years, though the routes vary.
  • A few IDs only have data for one or two years (e.g., some of the later-numbered animals).
Code 
spring |>
  st_drop_geometry() |>
  arrange(id, year, timestamp) |>
  ggplot(aes(longitude, latitude, color = factor(year), group = interaction(id, year))) +
  geom_path(linewidth = 0.4) +
  facet_wrap(~id, scales = "free") +
  scale_color_brewer(palette = "Dark2", name = "Year") +
  labs(
    title = "Spring migration",
    x = "Longitude", y = "Latitude"
  ) +
  theme_bw(base_size = 8) +
  theme(
    strip.text = element_text(size = 6),
    axis.text  = element_text(size = 5)
  )

Fall migration pathways
